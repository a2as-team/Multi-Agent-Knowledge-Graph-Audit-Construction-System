# Reference Materials

This directory contains reference materials from the course and other sources used to implement the system.

## Structure

### `course/`
Contains course code files organized by component type to match the main repository structure:

- `agents/` - Course agent implementations
- `tools/` - Course tool implementations  
- `pipeline/` - Course pipeline/orchestration code
- `neo4j/` - Course Neo4j integration code
- `utils/` - Course utility/helper code
- `other/` - Other course materials (configs, examples, etc.)

## Usage

1. Copy course code files into the appropriate subdirectory
2. Reference these files when implementing the corresponding components in `src/`
3. Adapt course code to work with our art collection use case and file structure

## Notes

- These are reference files only - do not import or use directly in the main codebase
- Files here serve as templates/guides for implementation
- Keep original course filenames when possible for easy reference
